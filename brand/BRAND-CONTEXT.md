# AikyaThiran — brand context (from the planning chat)

## Name decisions
- **Final brand / domain: AikyaThiran — aikyathiran.in.** "Aikya" (ஐக்கியம்) = unity/together, "Thiran" (திறன்) = skill.
  Meaning: "skills, together". The name starts with "AI" (AIkyaThiran).
- Earlier working names: Thiran Labs, then ThiranAI. Rejected: ThiramAI (Thiramai Inc, Silicon Valley, owns thiramai.com,
  same software/productivity field; Thiramai LLP Chennai).
- Known "Thiran" conflicts to keep in mind: Thiran Technologies Pvt Ltd (Chennai), Thiran Softlabs, Thiran Solutions
  (Coimbatore), TN Govt "THIRAN" school scheme, THIRAN NUTPAM trademark (Class 41). Aikyam Intelligence Pvt Ltd exists.
- Legal company name at MCA can be different from the brand (like Sarvam AI = Axonwise Pvt Ltd). Not decided yet.
- Get a trademark lawyer check before filing "AikyaThiran" (file the full word).
- Target users: students (India first, Tamil Nadu roots, global later). Style reference: Notion / Slack / Canva;
  inspirations: Sarvam, Zoho, upGrad, GeeksforGeeks, W3Schools.

## Products (under AikyaThiran)
- **Thiran Skills** — skill tracks / courses with progress.
- **Thiran Paath** — study app: AI study helper, notes, planner (owner has an older repo "PaathAI").
- **Aikyam** — student community, groups, discussions.
- **Thiran Enterprise** — later, for colleges/companies.

## Logo
- **Chosen direction: "Sunrise T"** — bold teal T crossing a yellow rising sun. Simple, works at 16px and in one color.
  Files: `brand/logo/sunrise-T/` (symbol, white, app icons, SVG). The `logo*.svg` files still say "ThiranAI" in the
  wordmark — the web app uses the "AikyaThiran" wordmark from `frontend/src/components/Logo.tsx`. Make new AikyaThiran
  wordmark files when needed.
- History: rising-bars logo (rejected: looked like a mobile signal icon) -> T + gopuram tower + swoosh -> sun version ->
  detailed "coding version" with `</>` box (owner liked it; kept in `brand/logo/other-options/`) -> simplified global
  options (gopuram T, temple tower, sunrise T). Idea for sub-brands: same mark plus a small symbol (e.g. `</>` for
  Thiran Skills, a book for Thiran Paath).
- Avoid looking like the Tamil Nadu Government emblem (no lion, round seal or govt text).
